Gym-app

Dit is mijn selfhosted site.

Diensten

  • gym: Mijn persoonlijke gym app, het werkt ook samen met Authelia waardoor iedere gebruiker eigen accounts en data heeft.
  • notes: Hier kan je notities maken met memos.
  • food: Dit is waar je voedingswaarde kan tracken om ze dan in de persoonlijke gym app te zetten.
  • status: Een status pagina waarin je kan zien of de andere services online zijn
  • auth: Dit is de service die wordt gebruikt om de andere services logins te geven / te linken aan dit account.
  • info: Deze pagina geeft een kort overzicht en is bereikbaar zonder login.

Beveiliging

  • Poorten 80 en 443 staan open op de VPS en 80 (http) wordt automatisch doorgestuurd naar 443 (https)
  • Alles heeft 1 login via Authelia behalve deze pagina.
  • Databases zitten op interne netwerken en de persoonlijke app spreekt zijn database aan via een api zodat er niets gelekt kan worden.
  • Geen geheimen in git

Backups

Er wordt iedere nacht een backup gemaakt met restic. Het maakt een kopie op zowel de laptop als op de VPS

CI/CD

Wijzigingen worden doorgestuurd naar GitHub actions waar het eerst nog getest wordt. Een systemd-timer controleert dan om de 5 minuten of er een nieuwe versie is. Zo ja dan haalt het deze op
